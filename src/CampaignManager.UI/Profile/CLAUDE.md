# Profile (UI) — личный кабинет

`/profile` (`ProfilePage`) — имя, роль и заявка на Хранителя, сводка «Мои игры», «Мои данные». Данные — только
`IProfileApi`; правила — [Server/Profile/CLAUDE.md](../../CampaignManager.Server/Profile/CLAUDE.md). Кабинет видит
**игрок** — проверять и на телефоне (390×844). Знание перенесено из `Features/Profile` v1; обходы (перезагрузка
страницы ради claim, `UserClaimsCache`, кэш настроек на circuit) — нет.

- **Имя в меню обновляется без перезагрузки**: после сохранения страница зовёт `IUserSession.RefreshAsync()`
  (`UI/Identity`), его реализует `MeAuthenticationStateProvider` в `Web.Client` — перечитывает `/api/v1/me` и
  оповещает `AuthorizeView` и `MainLayout`. В v1 был `NavigateTo("/profile", forceLoad: true)`: в WebAssembly это
  перезапуск всего приложения.
- **Галочка «Заменить и имена в кампаниях (N)»** — выключена по умолчанию и видна, только если псевдонимы есть
  (`AliasCount > 0`); снимается после каждого сохранения. Подпись говорит, что она сделает: сбросит своё имя в этих
  кампаниях. Кнопка «Сохранить имя» активна при новом имени **или** отмеченной галочке.
- **Заявка на рассмотрении (UX-2 X1)**: форма «Сообщение администратору» с текстом заявки — «Сохранить текст» (выключена, пока текст не менялся) и «Отозвать заявку» (подтверждение; строка на сервере удаляется, форма подачи возвращается). Если администратор успел решить — 409, тост и перечитанный кабинет.
- Заявка: статус бейджем (`RoleLabels.Status`/`StatusTone`), дата — `LocalTime`, комментарий отказа; форма с
  необязательным текстом — только при `CanApply` (игрок без заявки на рассмотрении). Хранителю и администратору
  блока заявки нет.
- Роли и статусы — `UI/Identity/RoleLabels` (одна копия на кабинет и админку). Цвет бейджа роли — `Tone`, а не имя
  цвета: в v1 бейджи «yellow»/«red» рисовались одним цветом.
- Почта видна только самому человеку (шапка карточки и «Мои данные»), рядом — что другим она не показывается.
- «Выйти» — в шапке страницы (как в v1) и в меню оболочки.
- Экрана настроек нет: первые настройки появятся с фонотекой (T2.8) и нижней навигацией (M2); API готов.

Тесты — `UI.Tests/ProfilePageTests` (bUnit): галочка выключена и есть только при псевдонимах, сохранение шлёт флаг
и перечитывает сессию, Хранителю формы заявки нет.

- UX-1 U1: секция «Заявка на роль Хранителя» — только у игрока (у Хранителя и администратора роль уже названа бейджем профиля);
  «Подать заявку» — главная кнопка; «Применить это имя во всех кампаниях» (`cm-tap-row`, 44px); у выключенного «Сохранить имя»
  причина рядом; «Сыщики» в «Моих играх» — строка без ссылки (списка листов нет).
